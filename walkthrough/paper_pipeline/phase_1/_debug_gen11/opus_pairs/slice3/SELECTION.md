# SLICE 3 — clause selection (deterministic, no hand-picking)

## Rule applied

1. Corpus: `resolve_runs/graph_v2/node_corpus_all.json`, loaded through
   `translate.load_corpus` with `resolve_runs/graph_v2/config_corpus_all.json`
   (the config the `ds_opus_loop` cohort itself used). Node ids taken from the
   config's `corpus.id_key`.
2. Sorted by node id, plain `sorted()` (byte order on the id string).
3. Excluded: every id with any file in `_debug_gen11/ds_opus_loop/out/`, and
   every id with a module in `_debug_gen11/reference_set/modules/`. Only the
   FILENAMES of `reference_set/modules/` were read — no content was opened, per
   the fence.
4. Slice 3 = `eligible[2::5]`; the first 5 of that stride are this slice's
   clauses. Slices 1/2/4/5 take offsets 0/1/3/4, so the five slices cannot
   collide.

## The five clauses

| # | eligible index | clause id | kind | one line |
|---|---|---|---|---|
| 1 | 2 | `l1001_1107_n003` | meta | `**Example**:` lyrics of a song not in the public domain — GOOD/BAD comparison block |
| 2 | 7 | `l1001_1107_n009` | conditional | office vs personal phone number of a public official |
| 3 | 12 | `l1108_1367_n001` | conditional | no erotica / non-consensual / extreme gore, EXCEPT scientific, historical, news, artistic … |
| 4 | 17 | `l1108_1367_n006` | conditional | must not generate hateful content targeting protected groups |
| 5 | 22 | `l1108_1367_n011` | conditional | `#### Do not contribute to extremist agendas … {#avoid_extremist_content authority=root}` — a HEADING |

The stride lands all five in the `l1001`–`l1367` region of the id ordering.
That is an artifact of sorting by id and taking a contiguous stride prefix, and
it is recorded rather than corrected: substituting spread-out ids would be the
hand-picking the brief forbids, and the five spans are in fact heterogeneous
(one worked-example block, one narrowed norm, one exception-bearing
prohibition, one flat prohibition, one section heading).

Two of the five are abstention-trigger shaped on their face — `n003` is headed
`**Example**:` and `n011` IS a section heading, and `00_task.md` lists both "it
is an example" and "it is a section heading" as abstention triggers. This was
not selected for; it is what offsets 2 and 22 happened to be. It makes the
slice a good instrument for measured gap #1.

## Reproduce

```
../../../../../semi-formal-experiment/.venv/bin/python - <<'PY'
import os, re, sys; sys.path.insert(0, 'walkthrough/paper_pipeline/phase_1')
import translate
cfg  = translate.load_config('.../resolve_runs/graph_v2/config_corpus_all.json')
rows = translate.load_corpus(cfg)
ids  = sorted(r[cfg['corpus']['id_key']] for r in rows)
excl = {m.group(1) for f in os.listdir('.../ds_opus_loop/out')
        if (m := re.match(r'^(l\d+_\d+_n\d+)\.', f))}
excl |= {m.group(1) for f in os.listdir('.../reference_set/modules')
         if (m := re.match(r'^(l\d+_\d+_n\d+)\.json$', f))}
print([i for i in ids if i not in excl][2::5][:5])
PY
```

Span files were regenerated byte-for-byte by the production builder
(`translate.build_user`) into `spans/`, alongside the exact system block
(`spans/_prompt_system.txt`, from `config_corpus_all.json`'s `system_files`:
`prompt/00_task.md`, `prompt/10_output_format.md`,
`resolve_runs/graph_v2/node_worked_example.md`, `prompt/30_failure_modes.md`).
No cross-references resolved for any of the five, so no clause is missing
context that the production run would have had.
