## 1. THE ABSTENTION ANSWER

`00_task.md` names four triggers. Each is checked **by name**. The answer is
**do not abstain — translate**, and here is the answer trigger by trigger.

### (a) "it is a section heading" — NO
L1316 is a full finite sentence carrying a modal (`The assistant should not engage in …`),
not a heading. It sits *inside* the `#avoid_abuse` section (the section is what the
`user_authority` NEEDS gloss identifies) rather than naming it. The corpus's heading nodes
look like `l3995_4164_n001` in `node_worked_example.md` — a node whose entire content is
"the rules under this heading carry authority X". This node's content is a norm about
conduct. Not a heading.

### (b) "it states a goal rather than a condition" — NO
The span is explicitly conditional in both directions, and the node's own `kind:` field says
`conditional`. It has a governed act (`engage in …`), a triggering condition (the conduct is
gratuitous, abusive/harassing/negative, and directed at an individual), and a named defeater
(`unless explicitly instructed to do so in a context that does not violate other
principles`). A goal statement — "we aim to be helpful" — has no situation that violates it.
This one does: an assistant that gratuitously abuses an individual, uninstructed, violates
it. `REVIEW_LIST` P2's ask ("is the bearer the assistant/model?") answers *yes, the
assistant*, so this is a norm and not a fact about OpenAI or about the document.

### (c) "it is an example" — NO
This is the trigger the previous cohort failed silently, so it is worth being explicit.
There is no `**Example**` heading, no good/bad response pair, no dialogue, no "for
instance". `REVIEW_LIST` P10's ask ("if the span is a GOOD/BAD pair, do the two arms
differ?") is **not applicable — the span is not a GOOD/BAD pair**, and I record that
rather than leaving it silent. The span contains a fragment of exemplification —
`(such as …)` — but that is an example *inside* a norm, illustrating what "other
principles" ranges over; it does not make the span an example clause. A norm that
contains an illustration is still a norm.

### (d) "its content is not expressible as rules" — THE LIVE ONE. Argued at length.

**Why this is live.** The node's narrowing is truncated mid-phrase. It ends at

> `…in a context that does not violate other principles (such as`

with the object of *such as* physically absent, because in the document it is a bare
markdown link `[?](#avoid_hateful_content)` with no visible label, and the anchor
`avoid_hateful_content` is flagged by the input itself as **"referenced but not resolvable
in the corpus."** So the module is asked to translate an exception whose scope-limiting
phrase is (i) an open-ended reference to the rest of the document (`other principles`) and
(ii) illustrated by a token that does not exist anywhere the translator can read.
`ESTABLISHES` silently repairs this, rendering the tail as `(such as the avoid hateful
content principle)` — content the narrowed span does not contain. Under `PROVISIONAL.md`
("`ESTABLISHES` may direct **which** claim of the span the module is to express. It may
not: **add** content the narrowed span does not state") `ESTABLISHES` is **not entitled to
that repair**, and a module that followed it would be writing an `assumed`-at-best fact
behind a `textual` citation.

**The case FOR abstaining.** A rule's guard has to be determinable, or the rule is
`30_failure_modes.md` #5, a *hollow stub*: "One opaque symbol echoing the document's own
words reads correctly in every explanation while the referenced content is absent.
**Survives a paraphrase check by construction.**" The guard here is exactly of that shape:
*does this context violate some other principle?* The set of "other principles" is never
enumerated in this node, the one worked example of the set is unreadable, and `00_task.md`
rule 5 says in terms: "If the content is not in this clause, it belongs in `requires`" —
and there is no single provider node that can be named as owning "the other principles",
because it is a relation over the whole corpus. On that reading the exception arm is
untranslatable and the honest answer is to decline.

**The case AGAINST abstaining, which I hold is right.** Three grounds.

1. **What was cut is exemplificatory, not restrictive.** `such as X` in English narrows
   nothing: it offers one member of a set already named by the head phrase, `other
   principles`. Delete "(such as the avoid hateful content principle)" from the sentence
   and the norm's truth conditions are unchanged. Contrast `N4`'s methamphetamine
   parenthetical — *"(without specific ratios or integration techniques)"* — which is
   **restrictive**: deleting it changes the scope of a permission, and dropping it was the
   measured harm. Losing an *illustration* costs the module a worked example; losing a
   *restriction* costs it the rule. This truncation is the former. The two finite verbs of
   the narrowed text (`should not engage`, `does not violate`) both survive intact, so
   `N9`'s count check ("how many finite verbs does the narrowed text contain, and how many
   propositions does `ESTABLISHES` demand?") comes out even: two verbs, and the four
   entries of `claims` decompose those two rather than adding a third proposition.
2. **The direction of the surviving error is the safe one.** If "other principles" is read
   too broadly, the exception fires less often and the **prohibition** stands more often.
   For a prohibition in a section about abuse, under-excepting is the conservative
   direction, and `PROVISIONAL.md` ground 3 is precisely that asymmetry: "an
   under-assertion stays visible and citable."
3. **Untranslatable-in-part is not untranslatable.** `node_worked_example.md` gives the
   three-way route: "a node stating a norm goes to `asserts`; a node stating a **structural
   fact** … goes to `ontology` … only a node that establishes *neither* is an abstention."
   This node establishes a norm — a prohibition on gratuitous abuse — that is complete and
   citable without the missing token. Abstaining would delete a real, readable prohibition
   from the corpus in order to protest a missing hyperlink label.

**Is the module's handling honest?** Yes, and this is the crux. The module coins
`context_violates_other_principle/1` glossed *"acting in context C would breach some
principle of this document other than the one stated here"* — the **generalisation**. It
does **not** substitute the hateful-content principle for the missing example. Verified
mechanically: `restricted_content_rule` appears in **no body** of this module, and the
string `hateful` appears in **no body and in no read-back**. Assert 2's read-back says "the
context % is one that violates **another principle**", not "violates the hateful-content
principle." That is the one thing the truncation invited the module to get wrong, and it
did not get it wrong.

**Conclusion: translate. Trigger (d) is raised, argued, and answered in the negative** —
the missing token is an illustration, the norm survives it, and the module's guard is
pitched at the generality the surviving text actually states.
