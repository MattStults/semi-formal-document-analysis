## UNSURE — what I could not settle

**UNSURE-1 (substantive, the one that matters).** The prohibition fires only where the case
supplies `outside_specific_circumstances(C)`. A test case that says "the user asked for erotica"
and nothing else derives no violation from this module. I believe this is right — N5 forbids
the negation-as-failure alternative, and the `e.g.` list cannot be closed so the complement
genuinely cannot be computed — but it means the module's force depends on a case-side fact
whose supplier is outside this clause, and I cannot verify from one clause that the corpus's
case vocabulary will ever supply it. If the intended reading is instead that *any* generation
of sensitive content is forbidden until a circumstance is shown, the body should be
`sensitive_content(C)` alone with the circumstances handled as defeaters elsewhere — a strictly
stronger module. I did not take that reading because it asserts a prohibition the span
conditions.

**UNSURE-2 (contract).** `no_erotica_or_gore` and `transformation_exception` are pointed at by
the span and reported unresolvable in the corpus. Contract 2 and the `l3995_4164_n001`
precedent put them outside `requires` (they are not `NEEDS` names), so this module records no
cross-reference to either — while failure mode #2 says a clause modifying rules defined
elsewhere should declare the dependency. I followed the node contract, since `NEEDS` is stated
to be authoritative and the anti-rule warns specifically against moving names around to make a
module look complete. If the coordinator's rule is that resolvable-or-not hyperlinks in the
span become `requires` entries, this module is missing two, and that is a one-line fix.

**UNSURE-3 (closure).** `closure: unclear` on act class `generate`. `cnpa` is arguable for the
sensitive-content subclass — "may only" does make generation the exception rather than the
default there — but the act class is `generate` at large, and declaring `cnpa` on it would
commit the corpus to "generating anything is prohibited unless permitted", which this span
plainly does not say. `unclear` is the honest reading of a class this clause governs only
partly. I record that a schema able to scope a closure to a *conditioned* act class would not
force this choice.

**UNSURE-4 (minor).** The glosses on `erotica/1` and `gore/1` spell out what the two words mean
("sexually explicit material", "graphic depiction of injury"). The span names them without
defining them, so strictly the meaning is ordinary-language knowledge, not textual. I marked
both `textual` because the fact being licensed is *that these are sensitive content*, which the
span does say; the definitional content sits in the gloss, which the format requires to be
non-circular. A stricter reader could want `assumed` on both.
