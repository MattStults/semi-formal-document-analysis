## L7 — A CLEAN CALL YOU PRE-REGISTERED IS STILL A CALL, AND PRE-REGISTRATION PROTECTS ITS TIMING, NOT ITS TRUTH

**Ask, of every item you pre-registered as *"I will accept either reading"*:**
is there a **ruling file** that already decided it? Pre-registration proves you
were not reasoning backwards from the draft. It does not make you right, and it
must not be allowed to function as a licence to stop looking.

**Why it is new.** Clause 2's L6 established that *a clean call is a finding
too, and the list should be run against the clean calls.* This is one level
further in and it is the harder case: **the clean call here was pre-registered
before the draft existed**, complete with its reasoning, which is precisely the
protection the protocol offers — and it was **wrong anyway**. `PROVISIONAL.md`
rejects my T11 argument (*"`ESTABLISHES` governs, because it is the node's
contract and names the one claim the module must express"*) **by name**, in a
file I had not read because it is not part of the blind-pass material. The
pre-registration made the error legible and dated; it did nothing to prevent it.

**The transferable part:** a pre-registered clean call is the item on the list
**most** likely to survive step 3 unexamined, because it arrives wearing the
protocol's own seal of good conduct. Run the list against it hardest.

## L7b — THE COROLLARY THAT COST AN EDIT, AND IS THE MECHANICAL PART

**Ask, before every edit that makes prose agree with code:** which of the two is
the *defective* one? The P1 anti-rule says *"never make `status` and `read_back`
agree by rewriting the read-back — the two are written independently and that
redundancy is the only place a wrong status is visible."* **That mechanism is
not about `status`.** It is about **any** independently-written pair.

**Measured here.** Turn 1's read-back named two of the body's three conjuncts,
and so did claims C1 and C2. My blind remedy was to add the missing conjunct to
the read-back. **The read-back, C1 and C2 were the draft's own three
independent votes that the third conjunct did not belong**, and the edit I had
drafted would have deleted that evidence while leaving the defect. The correct
edit was the opposite one — delete the conjunct — and it discharged the finding
and the reversed clean call together.

**The rule, stated so it generalises:** when prose and code disagree, the
disagreement is the *measurement*. Spend it on deciding which side is wrong.
Never spend it on agreement. → **R33.**
