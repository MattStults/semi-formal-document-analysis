## 3. THE SPAN, WORD BY WORD

| fragment | what it is | encoding question |
|---|---|---|
| *"By default"* | a **defeasibility marker** | there is **no schema field for defeasibility**. `closure` is about the document's silence on an ACT CLASS, not about this rule being overridable. So it can go only in `claims`, or in a read-back, or nowhere. |
| *"the assistant"* | the bearer | `assistant_definition` is the `NEEDS` name for it. |
| *"should"* | deontic force | `oblige`. `guideline_authority` says the force is **guideline**, not hard rule — but the schema's `Status` has no strength axis. |
| *"express uncertainty"* | **the act** | `express_uncertainty(...)` — indexed. |
| *"naturally"* | **manner adverbial #1** | a constraint on HOW, not on WHETHER. |
| *"using conversational language"* | **manner adverbial #2** | second adverbial on the same verb; arguably the *means* by which #1 is achieved rather than a second independent requirement. |

⭐ **THE STRUCTURAL FACT OF THIS SPAN: it is a MANNER constraint, not an act
requirement.** The sentence does **not** say the assistant must express
uncertainty. It says that *when it does*, the expression should be natural and
conversational. A faithful module's obligation must therefore be **conditional on
an expression of uncertainty existing** (or must oblige a manner-typed act). An
unconditional `oblige express_uncertainty(A)` says something the span does not:
that the assistant must always be expressing uncertainty.

⭐ **`PROVIDES` NAMES THE MANNER CLASS, NOT THE ACT.**
`natural_uncertainty_expression` is a **classification of an expression** — the
node's own gloss is the whole sentence, which is unhelpfully broad, but the name
is a noun phrase describing a thing, not a verb. Putting it in an `asserts` act
slot (`oblige natural_uncertainty_expression(E)`) is the *material-in-an-act-slot*
error `10_output_format.md` names — and it is the **path of least resistance**,
because `PROVIDES` hands the name over and the schema wants an act.

**Rule 5b check, run now so the ruling is pre-registered and not retrofitted.**
Is *"should express uncertainty naturally"* a comparative? **No.** 5b's test is
*"there is no situation that violates them"*; answering *"I am 87% confident"*
**is** a violating situation, named as such by the very next sentence of the
source text. `prefer` would be **wrong here**, and `oblige`/`forbid` right.

**Rule 4 / NAF check.** *"By default"* has **no stated exception inside the
span** — the `Unless` clause lives in S2, which the node excluded. So there is no
positive ground available for a defeater, and the honest options are (a) say
nothing about defeasibility in the rules and record it in `claims`, or (b) name an
`assumed` input. `not overridden(...)` would be rule 4's exact prohibition with
nothing to license it.
