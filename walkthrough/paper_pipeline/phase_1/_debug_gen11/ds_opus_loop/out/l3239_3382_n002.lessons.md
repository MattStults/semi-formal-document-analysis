# `l3239_3382_n002` — NEW mistake classes

Two, each phrased as a mechanical question, plus one that is a lesson about the
**adjudicator** rather than the translator. Everything else this clause produced
was an instance of a class the review list already has (P6, P7, P8, N1, N3, N7,
N9, N10) and is **not** repeated here.

## L4 — A CLOSURE is a field the body edit forgot

**Ask:** for every act class whose body you narrowed, what does its `closure`
say about the instances the new condition excludes? If `cepa`, you obliged the
narrow case and **permitted** the wide one, and the condition bought nothing.

**Why it is new.** P5's ⚠️ says a body added for faithfulness *weakens* the
rule. N7's second half says a `cepa` on an excepted branch re-asserts a silence.
This is neither: the body edit is **correct**, and a **different field, not
named in the edit**, silently undoes it. Measured here at turn 2 —
`reasonable_to_address(I)` was added to `oblige address_implied_intent(I)`
exactly as instructed, while `closure: cepa` on that act class stayed, and
`00_task.md` line 103 defines `cepa` as *"silence about that act permits it"*.
The module obliged the reasonable case and permitted the unreasonable one.

**Where it breeds:** mechanical numbered repair, precisely because a good edit
names one field. Every artifact — body, read-back, claim — looks right in
isolation, and the defect is only visible by reading two blocks against each
other.

## L5 — A name the node COMMISSIONS is not a name the node DEFINES

**Ask:** for each `PROVIDES` name, which head in **your** module derives it —
and does the narrowed span supply any criterion for it at all? If the answer to
the second is no, say so in the module; do not manufacture a body.

**Why it is new.** P9 (corrected) asks whether names YOU coined are used. N1
asks whether a ground atom will ever match a situation. Neither asks the
prior question: whether the module discharged the obligation to **supply**
something. Measured here twice over — the turn-1 draft filed the PROVIDES name
under `requires` (the graph edge reversed, and no check reads the PROVIDES
block: `grep -l provides checks.py link.py fixtures.py` returns nothing), and
when the name was correctly moved, the span turned out to state **no criterion**
for it, so the only honest definition was a ground fact about the document plus
a normative judgement pushed into `inputs`. The turn-1 tautology
`overstepping(A) :- …, overstepping(A)` was the draft writing that circularity
down literally.

## L6 — a lesson about THIS PROTOCOL, not about the translator

**Ask, of the adjudicator:** when the blind pass records something as *clean*
and *praiseworthy*, was that call checked against the standing ruling files, or
only against the span?

**Why it is worth recording.** The blind pass on this clause called the hardest
judgement — keep or drop *"without overstepping"*, which `ESTABLISHES` includes
and the node's narrowing excises — **correct and unprompted**, in praise. It was
wrong: `PROVISIONAL.md` rules that the narrowed span governs, and P6, N3 and N10
all point there. The list did not add detail to a finding I had; **it reversed
the sign of one.**

This is the first time in three clauses the list has caught the **adjudicator**
rather than the translator, and it locates a real hazard in the FRESH/FROM-LIST
metric: a blind pass produces false CLEANs as well as missed findings, and only
the missed findings are being counted. **A clean call is a finding too, and the
list should be run against the clean calls, not only against the defects.**
