## ⭐ NEW MISTAKE CLASS — AN `ontology` ENTRY THAT INVERTS ITS SPAN'S IMPLICATION, SO A TWO-CONJUNCT ANTECEDENT BECOMES A ONE-CONJUNCT SYNONYM

**Ask, of every `ontology` entry: which direction does the span state?** Write the
span's sentence as *"an X is a thing that is P and Q"*, then read the entry. If the
entry is `x(A) :- p(A)`, the span's *"an X is P"* has become *"anything P is an X"*
— and Q has left the module entirely.

```
span:  "When interacting with THIRD PARTIES on behalf of the user …"
entry: third_party_interaction(A) :- on_behalf_of_user(A).
```

**Why it deserves its own class.** Every prior "the antecedent is wrong" class in
this run is about the antecedent's **presence**: dropped (P3, clause 9's H1), added
(P5), mis-propagated (N4, clause 8's R42), unable to discriminate (clause 9's F4).
**Here the antecedent is present in every body, spelled correctly, and its own two
glosses name both conjuncts** — the loss is one inference step below, in a
definition that is individually well-formed and correctly shaped.

⚠️ **The nearest existing entry, N1, passes it.** N1 asks *"will a situation fact
ever unify with this atom?"* — and one will: `on_behalf_of_user(a)` derives
`third_party_interaction(a)` perfectly well. The rule fires. **It fires on the wrong
set.** Clause 9's R45 is the closest relative (a defect visible only by comparing two
things), but R45 compares two *entries*; this one compares an entry against **the
sentence it came from**.

⭐ **And the damage is asymmetric in a way worth stating separately**, because it is
what makes the class dangerous rather than merely wrong. The inversion **widens** the
antecedent, which on the `forbid` is over-strict and harmless — and on the `permit`
means the module **licenses lying by omission to the user**, from a clause entirely
about third parties. **One entry, two directions, and only one of them is visible as
a mistake.** P5's *"BOTH directions, and the counter-intuitive one"* is the list
entry that names the asymmetry; it does not name this mechanism.

⭐ **Operational form:** at step 3, run the **ANTI-RULES section against your drafted

that look correct and are damage.** ⚠️ **And do not obey them mechanically either:**

forbidden"*) and **vacuous** for `oblige honest_and_forthright(A)` (*"honesty is
obliged where honesty already obtains"*). The anti-rule's wording covers only the
prohibition, and the split had to be reasoned, not applied.
