## ⭐ NEW MISTAKE CLASS 1 — THE ANALOGY LEAK: content that IS in the span, IS in the document's own voice, and is about something the document does not regulate

Every unanchored-content class in this run so far asks *where did this come
from?* — N10 (*"which substring of the narrowed span?"*), P6 (*"is it inside the
narrowing?"*), failure mode #1 (*"made-up things"*). **All three pass this
defect.**

The span is *vehicle → `Similarly` → tenor*:

> S2 *"…**the manual itself** … should not be disclosed **unless policy
> explicitly allows it**."*
> S3 *"Similarly, **the assistant** can share its identity and capabilities,
> while keeping the underlying system or developer prompts **private by
> default**."*

The draft put `not policy_explicitly_allows(P)` into the body of a prohibition
about the assistant's prompts. The phrase is **verbatim in the narrowed span**.
It is **not** a hallucination, **not** outside the narrowing, and **not** taken
from `ESTABLISHES` (which reproduces the same analogy). It belongs to a
**training manual belonging to a customer-service agent** — an entity nothing in
the corpus will ever instantiate.

**Why it deserves its own class:** the whole existing apparatus is built to catch
content whose *provenance* is wrong. This is content whose provenance is
impeccable and whose **attachment** is wrong. The nearest entry is N4 (*a
qualifier in a list bounds ONE item*), which is about attachment — but N4 is
scoped to a list inside one sentence, and this crosses a sentence boundary and a
change of subject.

⭐ **The mechanical move, and it is cheap:** for every conjunct of every body,
name **the sentence** it came from, then ask **who the subject of that sentence
is**. If the subject is not the assistant, the conjunct is illustration.
N2 already supplies the test (*strip the matrix verb; score on the matrix
subject*) — **it was written for deciding whether a SPAN is translatable, and
this class is it applied per-CONJUNCT.** → **R42**.

⚠️ **The trap is that an analogy is normative-sounding on purpose.** S2 contains
*"should not be disclosed"* and an *"unless"* — it is the most rule-shaped
sentence in the paragraph, and it is the one sentence that governs nothing.
