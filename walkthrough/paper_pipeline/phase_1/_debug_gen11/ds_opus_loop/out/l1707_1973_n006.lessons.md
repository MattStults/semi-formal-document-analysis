# `l1707_1973_n006` — NEW mistake classes

Three, each phrased as a mechanical question. Everything else this clause
produced was an instance of a class the review list already has (P3, P9, P10,
N5, N7, N9) and is **not** repeated here.

---

## L1 — A gloss written for a DECLARATION, then not revisited when the name gets a DEFINITION

**Ask:** does any name have BOTH a `concepts` gloss and an `ontology` body? If
so, list the body's conjuncts and list the gloss's conditions, and check they
are the same set. A gloss that names fewer is a dropped conjunct a reviewer will
never see; one that names more is a condition the solver does not enforce.

**Why it is new.** P8 asks whether a gloss restates its own predicate name.
This is the opposite failure: the gloss is a perfectly good, informative,
*different* definition. Measured here at turn 2 — the gloss said *"explains
possible causes and suggests precautions without giving a definitive
diagnosis"* while the body computed
`explains_possible_causes(R), suggests_precaution(R), advises_consulting_doctor(R)`.
It survived a clean stage-2 floor. The mechanism is the transferable part: the
gloss was correct when written, and acquiring a body is exactly the edit that
does not prompt anyone to re-read it.

## L2 — A GOOD/BAD pair whose arms OVERLAP

**Ask:** can one situation satisfy both arms' bodies at once? Differing in
`status` is not enough — that is all P10 checks, and it passed here while a
response matching both was permitted and forbidden simultaneously.

**And ask it in the right direction:** the guard that separates the arms is
almost always a *negative* ("without giving a definitive diagnosis"), which is
why it ends up in a gloss instead of a body. It must be a POSITIVE predicate in
the body (N5), never `not p`.

## L3 — A borrowed name arrives with a gloss and NO ARITY, and the arity choice silently RE-TYPES it

**Ask, of every NEEDS name:** what grammatical kind is the graph's gloss
describing — a rule, a relation, a property? Does the arity you chose describe
that same kind? Write the answer into your `concepts` gloss.

**Why it is new.** N8 covers argument *order* on a borrowed relation of arity
≥ 2. This is one level earlier and strictly worse, because there is not yet an
arity to disagree about. Measured here: the graph's *"**The rule that** the
assistant should equip users…"* came back as *"**R is subject to** the rule
that…"* — a rule re-typed as a property of responses, in a name used in no body,
so the only note raised was `requires-unprovided`, which the anti-rules record
as firing on every correct single-clause module.
