PRE-REGISTRATION — ABSTENTION BOUNDARY ADJUDICATION
written 2026-08-15, BEFORE any adjudication draw was dispatched and BEFORE the
key joining opaque ids to model choices was opened.

QUESTION
Is the pipeline's abstention criterion underspecified? Sized as: what fraction of
the disputed clauses are GENUINELY AMBIGUOUS under the criterion the prompt gives.

MATERIALS
* 53 items, opaque ids X000..X052, order shuffled under seed 777, key sealed in
  KEY_do_not_open_until_judged.json and not read until every judgement is on disk.
* Each item shows ONLY: the node's ESTABLISHES claim and the verbatim SOURCE TEXT
  block (including the `[node narrows this span to: ...]` line where present),
  taken from `resolve_runs/graph_v2/node_corpus_all.json`. No model output, no
  outcome, no model name, no stratum label.
* Strata (blind to the adjudicator):
  - cohort17    (17) the `undeclared-body-name` cohort DeepSeek translated and
                     Haiku abstained on in 17/51 draws
  - ds_abstain  (12) DeepSeek's 12 abstentions in the 08-14 100-clause pair
  - ds_success  (24) random sample (seed 20260815) of the 69 DeepSeek modules
                     with status `translated`, excluding any clause already in
                     the dispute set — the over-translation check (step 4)
  Note: the ds_success stratum is judged in the SAME shuffled pool as the
  dispute set so the adjudicator cannot condition on stratum.

ADJUDICATOR
One isolated local Haiku subagent per (item, draw). Never batched: an agent sees
exactly one item and answers once. 3 draws per item = 159 draws.

THE SINGLE QUESTION PUT TO EACH DRAW
"Does this span state an obligation, permission, prohibition or definition that a
logic module could faithfully encode, or is it a statement about the document, an
example, or commentary?"
Answer is one of NORMATIVE (encodable) / NON-NORMATIVE (about the document, an
example, or commentary), plus one sentence of grounds.

DECISION RULE (fixed here, before any result)
Per item, over its draws:
  3/3 NORMATIVE      -> item verdict NORMATIVE
  3/3 NON-NORMATIVE  -> item verdict NON-NORMATIVE
  2-1 either way     -> escalate to 5 draws; then 5-0 or 4-1 resolves to the
                        majority; 3-2 -> AMBIGUOUS
Escalation is decided on draw counts alone and is applied before the key is opened.

THE THREE-WAY SPLIT (join to model choices only after all verdicts are frozen)
  ABSTAINER RIGHT     item verdict NON-NORMATIVE and some model translated it
  TRANSLATOR RIGHT    item verdict NORMATIVE and some model abstained on it
  GENUINELY AMBIGUOUS item verdict AMBIGUOUS
Bucket sizes are reported over the 29-item dispute set with Wilson 95% intervals.

PRIMARY ENDPOINT
AMBIGUOUS fraction of the 29-item dispute set.
PRE-REGISTERED READING:
  * AMBIGUOUS >= 20% with Wilson lower bound >= 10%  -> the criterion is
    UNDERSPECIFIED; a prompt clarification is warranted and will be drafted.
  * AMBIGUOUS < 20% AND one model's choice is the minority verdict on a clear
    majority of the dispute set -> NULL on underspecification; report "one model
    is simply wrong" and drop the prompt change.
  * anything else -> report as indeterminate, do not draft.

SECONDARY ENDPOINT (step 4, over-translation)
Fraction of the 24 ds_success items judged NON-NORMATIVE, with Wilson 95% CI,
extrapolated to the 69 translated modules. This is only interpreted if the
ABSTAINER-RIGHT bucket in the dispute set is non-empty.

FALSIFIERS
F1 The adjudicator is not discriminating: if the ds_success stratum and the
   ds_abstain stratum receive statistically indistinguishable NON-NORMATIVE
   rates, the instrument cannot tell the classes apart and every number below is
   uninterpretable. Report as INSTRUMENT FAILURE.
F2 Degenerate answering: if >90% of all 159 draws give the same answer, the
   instrument is a constant and the split is meaningless.
F3 Prompt-order/wording artifact: the question names NORMATIVE first. If the
   NORMATIVE rate exceeds 90% overall, re-run a subset with the option order
   reversed before reporting.
F4 Haiku is not DeepSeek. Every judgement here is evidence about the
   INSTRUCTION as read by one model, not a guarantee for the production model.
   No finding is promoted to production trust without a DeepSeek re-run, and no
   such spend is authorised.
