What am I looking at?
When the relevance instrument disagrees with a blind judge about whether a passage bears on a behavior, that's a reported failure. This machine decides what kind of failure it is and what to do about it — mostly by computation, calling an expensive frontier-model "judgment seat" only at four specific points. You play the environment: at each step the router (blue box) asks one question, and you pick which answer the world gives. Costs accumulate in "units" (u), roughly the price of one frontier ruling. Every path provably ends at a green terminal — hover any box for what it does.
Census verdicts (computed free, no model): SEP = the failing passage is distinguishable from all correctly-handled ones using levers we can already pull → a small config change can fix it; REACH = distinguishable, but only by a feature nothing consumes yet → build the consumer first; UNSAT = indistinguishable with today's vocabulary → we must coin a new distinction, or accept the document doesn't support one.
