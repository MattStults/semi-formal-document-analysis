# `machine/` — the repo's own governance machine, as a queryable model

Questions about the cycle/seat/gate system used to be grep expeditions across
`CYCLE_DESIGN.md`, `MODULE_MAP.md`, `REPRODUCIBILITY.md`, `briefs/` and
`cycle.py`. This directory makes them queries.

**This is a transcription, not a design.** Every fact restates a rule already
written somewhere in the repo and carries the `file:line` it came from. Where a
rule is stated nowhere, it is recorded as a GAP below — never invented into the
model. `cycle.py` is the ENFORCEMENT and is authoritative over prose; where they
disagree, the disagreement is itself a fact (`disagreement/3`).

## Run it

```
.venv/bin/python machine/check_model.py              # the validator: 4 checks
.venv/bin/python machine/check_model.py --self-test  # RED-first proof, then GREEN
.venv/bin/python machine/scan.py                     # regenerate scanned.lp
.venv/bin/python machine/query.py                    # question list
```

Recurring questions:

```
machine/query.py human-seats            # which seats are human?
machine/query.py seats                  # tier x scaling unit x producer x validator
machine/query.py scaling per_flip       # which seats scale per flip?
machine/query.py gate g_flip_budget     # what does gate X bind / read / refuse on?
machine/query.py gates measure          # every gate in front of a phase
machine/query.py constant flip_budget   # where did constant Y come from?
machine/query.py constants              # every constant with its provenance
machine/query.py phases checkpoint      # phase order + overridability
machine/query.py artifacts measure      # what a phase produces/consumes
machine/query.py contradictions         # what contradictions exist?
machine/query.py disagreements          # recorded prose/code disagreements
machine/query.py source seat_tier       # the file:line behind any fact
```

`clingo` (5.8.0, in `.venv`) does all the reasoning; `query.py` is a thin
runner. `check_model.py`'s source and differential checks work without a solve;
only the acceptance check needs clingo.

## Files

| file | what it is |
|---|---|
| `facts.lp` | THE MODEL, hand-transcribed. 281 facts, each with a `source/3` + `needle/2` companion (955 more come from `scanned.lp`). |
| `scanned.lp` | GENERATED by `scan.py`. Facts nobody chose: retraction/assertion pairs, verdict records, the live cause taxonomy. |
| `rules.lp` | the integrity constraints. Derives `contradiction(Kind,A,B)`; the `strict` subprogram turns them into real `:- ` constraints. |
| `semantics.lp` | the allow/refuse fragment — what the model PREDICTS `cycle.py` will do, used by the differential check. |
| `scan.py` | the mechanical extractor. |
| `query.py` | the question runner. |
| `check_model.py` | THE VALIDATOR (below). |

## What the model covers

* **Phases** — `PHASES_BY_SHAPE` for both shapes (`code`, `checkpoint`), in
  order, with overridability derived from `cycle.OVERRIDABLE` and the refusal at
  `cycle.py:553` that makes the complement exhaustive. Plus the PREDICT
  demotion (`exploratory` ⇒ CLOSE refuses `keep`).
* **Gates** — 20 gates: what each blocks, what artifact/state it reads, which
  named constants its refusal turns on, and every condition it refuses on
  (quoted from the refusal message). Documented escape paths that are *not*
  `--override` are modelled separately (`escape_path`, `escape_validates_only`,
  `escape_unverified`).
* **Seats** — 12 seats (every file in `briefs/`): brief path, model tier
  (haiku / frontier / human — a seat may carry two when the repo says
  "a human, or a frontier model"), producer, validator, the phase it is used
  at, and its **scaling unit**: `per_flip`, `per_cycle`, `per_document`,
  `per_dossier`, `per_worksheet_row`, `per_behaviour`, `per_corpus`.
* **Constants** — 10, each with value, `file:line`, and PROVENANCE:
  `derived` (a document shows the derivation; `derivation/2` names it) vs
  `chosen` (asserted, no derivation exists anywhere).
  `FLIP_BUDGET = 30` is `chosen`; `NOISE_FLOOR = (0.0316, 0.037)` is `derived`.
* **Artifacts** — produces/consumes per phase.
* **Contradiction evidence** — mechanically scanned claim retractions/
  assertions and every verdict-shaped JSON artifact in the repo.

## What it does NOT cover

* **Only the cycle machine.** The scoring pipeline (annotate → atoms → query →
  benchmark), the panel, the anti-cheat perimeter and the FORBIDDEN/QUERY module
  fences are out of scope except where a cycle gate reads them.
* **No temporal semantics.** The model says what each gate refuses on, not the
  full state-machine trace. `semantics.lp` covers exactly the three gate
  families the differential check drives (override, flip budget, DECIDE).
* **`HARNESS_REDESIGN.md` is excluded entirely** from the scan
  (`scan_excluded/2` records why): other agents are editing it, so any line
  citation into it would be stale before it was read. Its content is therefore
  invisible to the model — including anything it says about `FLIP_BUDGET`.
* **The retraction scan reads only top-level `.py`/`.md`.** Subdirectory design
  docs (`cycles/*/`, `vocab_gap/`) are not scanned for retracted claims.
* **`cycle.py`'s OPEN/IMPLEMENT/CENSUS phases are not driven end to end** by the
  differential check — they need a real repo tree and real subprocesses. Their
  refusal conditions are transcribed and source-checked, not differentially
  tested. MEASURE, DECIDE and the override path *are* driven for real.

## The validator: three independent checks

`check_model.py` (plus the acceptance test):

**(a) SOURCE CHECK.** Every fact must carry `source(Fact, File, Line)` and
`needle(Fact, Text)`; the file must exist, the line must exist, and the needle
must appear at that line (Unicode dashes and whitespace normalised). It also
flags facts with no citation and citations to facts that do not exist. This
caught 26 wrong line numbers in the first draft of `facts.lp`, including several
that had drifted because concurrent edits moved `HANDOFF.md` by 55 lines.

**(b) DIFFERENTIAL CHECK against `cycle.py` — 282 comparisons.** The strongest
check. It imports `cycle.py` and:

* compares every closed vocabulary and constant *set-for-set* (`FLIP_BUDGET`,
  `OVERRIDABLE`, `PHASES_BY_SHAPE` incl. positions, `DECISION_VALUES`,
  `DIRECTIONS`, `DEV_CENSUS_CELLS`, `CLOSURE_DEFAULTS`) — an *extra* member is
  as wrong as a missing one, since it would widen a gate's accepted set;
* drives `Cycle._override` for real over the full 8×8×2 matrix of
  (current phase × `--override` target × reason present/absent) and compares
  allow/refuse against `semantics.lp`;
* drives `Cycle._measure` for real (with `_run` stubbed so no snapshot
  subprocess runs) over flips ∈ {0,1,29,30,31,34,60} × 5 plan shapes, comparing
  halt / proceed / refuse;
* drives `Cycle._decide` for real over all 96 combinations of
  decision × signed × justified × exploratory × prediction-failed × overridden.

**(c) KNOWN-ANSWER SET.** The five answers established by hand, each asserted
both positively and negatively (the model must say the right thing *and* must
not say the wrong thing):

1. the flip adjudicator is a MODEL seat (haiku-operable), not human;
2. `change_reviewer` and `decision_signer` are per-CYCLE, not per-flip;
3. `FLIP_BUDGET = 30` provenance is `chosen`, not `derived`;
4. PREDICT-freeze, ADJUDICATE-validation and the DECIDE signature are
   non-overridable (overriding PREDICT *demotes* rather than waives);
5. the `stratified_sample` escape validates only a resolution string and a
   non-empty rationale — no code draws or verifies the sample.

**RED-FIRST.** `--self-test` first proves each check fails for its own named
reason on a deliberately wrong model — a fabricated source line, a needle that
is not there, an unsourced fact, the flip adjudicator mislabelled human,
`FLIP_BUDGET` marked `derived`, a per-cycle seat relabelled per-flip, a constant
that disagrees with `cycle.py`, a phase wrongly marked overridable — and only
then runs GREEN. Output:

```
RED — each deliberately wrong model must be REJECTED for its own named reason:
  [PASS] fabricated source line
  [PASS] needle absent from the cited line
  [PASS] fact with no source companion
  [PASS] seat mislabelled human
  [PASS] FLIP_BUDGET marked derived
  [PASS] a per-cycle seat relabelled per-flip
  [PASS] a constant that disagrees with cycle.py
  [PASS] a phase wrongly marked overridable

RED — the acceptance test must fail when the scanned evidence for a known contradiction is removed:
  [PASS] section.py retraction evidence deleted
  [PASS] both_defensible verdict evidence deleted

GREEN — the real model must pass all four checks:
PASS (a) SOURCE CHECK
PASS (b) DIFFERENTIAL CHECK vs cycle.py (282 comparisons)
PASS (c) KNOWN-ANSWER SET
PASS (*) ACCEPTANCE TEST
```

## The acceptance test: both known contradictions surfaced

**PASSED, and neither was special-cased.** `scan.py` walks the repo without
being told where to look; `rules.lp` fires on what it finds.

1. **`section.py`'s retracted −0.143.** Rule: *a numeric claim retracted on one
   line of a file and still asserted on other lines of the same file*. The scan
   finds retraction markers (`RETRACTED`/`WITHDRAWN`) anywhere in the repo's
   top-level `.py`/`.md`, takes the numeric literals off those lines, and looks
   for them asserted elsewhere. Result includes
   `contradiction(retracted_claim_still_asserted_in_same_file,"-0.143","section.py")`
   — the retraction sits at `section.py:480`, the live assertions at `:82` and
   `:326`. (`REPO_TRAPS.md` §3 independently documents the same trap, which is
   a confirmation, not the source: the model was not given it.)

2. **The 27 `both_defensible` verdicts.** Rule: *a verdict whose `side` asserts
   no fault while its `cause` names a fault*. `side = both_defensible` means
   "the text genuinely supports both readings" (`briefs/disagreement_autopsy.md:140`),
   and the `CAUSE_TAXONOMY` marks each cause `FP` / `FN` / `either` — where
   `FP`/`FN` name a tool error (the validator itself pairs cause kind with the
   dossier's FP/FN kind at `audit_disagreements.py:532`) and two dedicated
   `either`-kind causes, `boundary_dispute_tool_defensible` and
   `boundary_dispute_panel_defensible`, exist for genuinely two-sided cases.
   Result: exactly **27** hits in
   `audit_dossiers/ext_v1_merged__audit_v1/verdicts_merged.json`
   (14 `fp_threshold_drift`, 13 `fp_promiscuous_atom`). **The two
   `either`-kind boundary_dispute causes are used ZERO times in the whole
   294-case census** — every genuinely defensible case was filed under a
   fault-asserting cause instead.

## GAPS — rules stated nowhere

1. **`FLIP_BUDGET = 30` has no derivation.** The only upstream statement is
   `ITERATION_LOOP.md` policy 4: *"more flips than can be exhaustively
   adjudicated (guideline: ~30)"*. Nothing shows how 30 was arrived at, and
   nothing says why the code enforces a strict `>` (30 flips passes, 31 halts)
   against a *guideline*. Recorded `provenance(flip_budget, chosen)`.
2. **The stratified-sample escape is unenforced.** `flip_budget_plan.json` with
   `resolution: stratified_sample` and a non-empty rationale lets MEASURE
   proceed; every flip is dossiered, and **no code draws the strata, checks
   strata coverage, or verifies the adjudicated set against
   behaviour × direction × cause.** The pre-registration is honour-system.
   `BUDGET_HALT` names the strata; nothing checks them.
3. **`FANOUT_DEGENERATE = 5`, `CLOSURE_DEFAULTS`, `DEV_CENSUS_CELLS`,
   `DIRECTIONS`, `DECISION_VALUES` are all `chosen`** — reasonable choices with
   stated rationales, but no derivations. Five gates refuse on a `chosen`
   constant (`machine/query.py contradictions gate_reads_chosen_constant`).
   This is not a defect per se; it is a list of the places where a refusal
   rests on an unjustified number.
4. **`attribution_author` has no producer and no validator.** `briefs/README.md`
   says "Producer/validator NOT YET BUILT". The sandwich rule (leg 3) is
   therefore unmet for that seat; it is a designed-but-unfenced seat.
5. **`golden_review` has no mechanical validator** — `MODULE_MAP.md:280`
   records it as `—`. Same class as (4), but deliberate: it is a human/frontier
   audit seat over a file that the author seat's sha-freeze already pins.
6. **`density_editor` is in `briefs/` but not in `briefs/README.md`'s list**,
   which still says "**11** as of 2026-08-05" while `ls briefs/*.md` returns 12.
   The list warns about itself ("this list has gone stale before"); it has.
7. **Nothing states a seat's scaling unit as a first-class property.** Each
   unit here is read off the brief's opening sentence ("You adjudicate ONE flip
   at a time", "for every row of a worksheet", "one cycle's keep-or-revert").
   There is no repo-wide statement of which seats scale with the size of a
   measurement — which is the property that decides what a change costs.
8. **No rule states what happens when two seats' legs diverge below the
   escalation bar.** `CYCLE_DESIGN.md` covers contested verdicts (recorded as
   contested, `unclear`, flagged) and `drift_standing.md` sets a >10%
   divergence bar; nothing covers divergence under the bar.
9. **The no-op short-circuit is undocumented as an ADJUDICATE bypass.**
   `cycle.py:964-969` appends `ADJUDICATE` (and `CENSUS`) to `state.completed`
   when the diff is a no-op. `CYCLE_DESIGN.md` F5 calls ADJUDICATE-validation
   non-overridable; this path completes it without validating anything. It is
   defensible (zero flips ⇒ nothing to adjudicate, and
   `_append_vacuous_checks` records the skipped targets as `PASS_VACUOUS`), but
   the design document does not name it as an exception.

## Known imprecision in the retraction scan

The scan reports 14 same-file retraction/assertion pairs. `section.py`'s
−0.143 and `test_structural.py`'s +0.310 / ±0.06 look like genuine live
contradictions. Three are a precision limit rather than a finding: in
`structural.py:323` and `ontology_prompt.md:181` the retraction line itself
*names the numbers it is suspending* ("GATE SUSPENDED: +0.340 is DRAW0 …"), so
those numbers reappearing elsewhere in the file is expected. `REPO_TRAPS.md`'s
hit is the document *about* the `section.py` trap. The rule is deliberately
kept loose — a retraction that names its own number is exactly the shape the
scanner cannot distinguish from a retraction that failed to propagate, and
narrowing it would have missed `section.py`.

## Keeping it honest

Re-run `check_model.py` after any edit to `cycle.py`, `briefs/`,
`CYCLE_DESIGN.md`, `MODULE_MAP.md` or `REPRODUCIBILITY.md`. The source check
goes red the moment a cited line moves, and the differential check goes red the
moment a constant or a refusal condition changes. Re-run `scan.py` after any
edit to a verdict artifact or a retraction marker.
