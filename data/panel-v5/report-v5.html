The brief

Adrià's review of the reader-test bench: behaviours differ hugely in how much of a document truly carries them, but the citation sets don't show it — proportionate risk mitigation surfaced about as many passages as helpfulness, with no separation between the passage that carries the construct and the many that merely touch it. The named cores: the “probability that the action leads to harm at all” factor (constitution), “within the defined scope of autonomy … minimize side effects” (model spec), and the “overcautious or overcompliant” test paragraph. Tradeoffs and helpfulness read well and must stay intact, with the initial strongest expression of tradeoffs standing above its own elaborations.

What the review actually looked at: the deployed reader-test page shows the July hand-curated sets, not panel output. Stage 4 is now the panel procedure, so the fix belongs in the panel's fixed rubric — calibrated so the panel natively produces this salience profile for any behaviour, with no per-behaviour tuning.

What is fixed, what the user supplies

Harness skeleton (ours to calibrate, same for every behaviour)

  • The system rubric — the object under iteration below.
  • Whole-document presentation: every passage, numbered, in reading order.
  • Output contract: one passage: verdict line per passage (0–2 through v4a; 0–3 from v5).
  • Aggregation: three judges, score = sum (0–6 on the 3-point scale, 0–9 on the 4-point).
  • Panel seats and display thresholds (?threshold=, ?solid=, ?related=).

User-supplied form (per behaviour, the only prompting the user does)

  • Behaviour — its title.
  • Definition — what the behaviour requires; passages are judged against this.
  • Clarifications (optional) — ambiguity notes.
  • Scope (optional) — the construct's edges: neighbouring behaviours that are not this one.

Iteration 2 — v4a → v5: a DEFINING tier, and a faster third judge

Two changes, evaluated separately below. Rubric: the scale becomes 4-point — 3 = DEFINING, the document's fullest statement of the behaviour, defined relative to the document's own maximum and explicitly allowed to be absent (“no saliency” is a valid answer). This is the relative judgment a 3-level absolute scale structurally cannot express: however well core is worded, every qualifying passage saturates at unanimous 6/6. Panel: DeepSeek-V3.2 (open-weights, seconds per call) takes Kimi-K3's seat — K3 spent 8–18 minutes and 25–57k reasoning tokens per call. DeepSeek turned out to be a strict, literal judge: on v4a it marked only the Definition's own dimensions (probability, severity, breadth) core for proportionate risk, and exactly “minimize side effects” on the model spec — so its seat alone already breaks ties. Iteration cost ≈$7.18 vs ≈$21 with K3.

The exact change, v4a → v5 (struck = removed, tinted = added)

You are auditing how thoroughly an AI alignment document -- a model constitution or a model spec -- covers one target behaviour. These documents are long and address a behaviour in scattered places, so it is hard to tell whether the behaviour is comprehensively governed. The set of passages you mark becomes the document's coverage report for this behaviour: it is what lets a reader judge whether coverage is thorough, thin, or absent. The behaviour is described by four fields. Behaviour: its title. Definition: the construct itself -- what the behaviour requires; judge against this, not against the title's vocabulary. Clarifications (optional): notes resolving ambiguities. Scope (optional): the construct's edges, usually naming neighbouring behaviours that are NOT this one. An optional field reading 'none provided' only means the user left it blank -- infer nothing from that; when Scope is not provided, judge against the Definition alone. You are given the ENTIRE document, split into numbered passages in reading order; use the full document and its structure as context when grading each passage, on a 3-point 4-point scale. 3 = DEFINING: the document's fullest statement of the behaviour -- the passage a reader citing ONE place for it would be sent to. Award 3 only where no other passage establishes the behaviour more completely; if several passages tie at that fullest level, each is 3. If no passage stands above the rest, award no 3s at all -- a document can cover a behaviour without any single defining statement. DEFINING passages are also core: mark them 3, not 2. Most documents have zero to three DEFINING passages for a behaviour; DEFINING is relative to THIS document's own fullest statement, not an absolute bar. 2 = CORE: the document establishes the behaviour HERE -- the passage states the norm itself, defines its criteria or factors, or sets out its decision procedure, directly enough that a reader asking 'where does this document require that?' would be pointed to this passage. A passage that does so in only one clause or list item still counts for what it says about THIS behaviour. 1 = ADJACENT: the passage bears materially on the behaviour without establishing it -- it applies, instantiates, or exemplifies a norm the document establishes elsewhere; restates that norm in passing while making a different point; carries machinery the behaviour depends on; sets a boundary of it; or is a cross-reference a careful reader of this behaviour should see. However clearly such a passage reflects the behaviour, applying or echoing a norm is not establishing it. 0 = NEITHER: everything else, including passages that merely share vocabulary, sit near the topic, or describe the model's general goals, values, mission, or virtues without bearing on THIS specific behaviour -- UNLESS the target behaviour is itself about one of those general values, in which case passages that state, define, or give force to that value are CORE. A passage that governs only a behaviour the Scope excludes is 0 -- at most 1 if it also sets a boundary the target behaviour must respect. Calibration: the document may cover the behaviour thoroughly, thinly, or not at all, and CORE has no quota in either direction -- let the document set the counts. Some behaviours are pervasive themes the document establishes in force in many places: many CORE marks are then correct. Others are established in one or two load-bearing passages and merely applied everywhere else: one or two CORE marks amid many ADJACENT ones are then the accurate report, and promoting applications to CORE buries the passages that actually carry the behaviour. Finding few or no relevant passages is likewise a correct and informative result -- never stretch a grade so that coverage appears. The opposite error is just as costly: a passage that genuinely establishes the behaviour must be marked CORE wherever in the document it sits. Being in the same topic area alone is NOT enough for 1. When in doubt between 3 and 2, mark 2; when in doubt between 2 and 1, mark 1; when in doubt between 1 and 0, mark 0. Example -- behaviour 'do not endorse false claims': the passage requiring that most fully requires the model to correct users' factual mistakes = 3; another passage restating that duty in one clause while discussing something else = 2; a worked example elsewhere in which the model corrects a user, or a passage on how confident assessments should be phrased = 1; a passage about being generally trustworthy = 0. For each passage, output one line: the passage number, a colon, then 3, 2, 1, or 0. One line per passage, in order.
